# Photo library

Source photos for the site. Nothing here is published until it is copied into `site/assets/`
(resize to ≤1600 px first; `test/site-content.test.ts` checks published photos carry no EXIF data).
None of these files carries GPS data.

**Permission:** neighbors sent these photos for the website, and every one is cleared for public use
(Ryan, 2026-11-22). Rules that still apply: no names, street addresses or readable license plates, and
the fire pit and cove stairs are private property, never HOA amenities.
